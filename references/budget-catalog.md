# 低预算好物目录与花钱优先级

价格均为人民币参考区间，随城市与平台浮动，输出时写成区间并注明"仅供参考"。

## 一、花钱效率排序（预算不够时按这个顺序砍）

从高到低，**每花一块钱带来的体验提升**：

1. **灯光**（¥100–250）— 换掉惨白顶灯，立竿见影
2. **窗帘**（¥80–200）— 遮光 + 私密 + 大面积色块，决定房间基调
3. **床品四件套**（¥100–300）— 占视觉面积最大，也是每天接触的东西
4. **地毯**（¥60–300）— 划出"我的地盘"，遮丑地面
5. **收纳**（¥50–150）— 消除视觉噪音
6. **绿植**（¥20–80）— 活的东西带来生气
7. **装饰画 / 照片墙**（¥20–80）— 个人痕迹
8. **香氛**（¥30–80）— 气味锚点，记忆最强
9. **大件家具**（¥200+）— 合租房最后考虑，尽量不买

**反例提醒**：先买摆件、香薰、小装饰是新手最常见的错误，它们对整体观感的影响不到 5%。

## 五、省钱渠道

- **闲鱼 / 转转**：同城自提的大件（灯具、镜子、架子）通常 3–5 折；搜"搬家急出"关键词
- **拼多多 / 1688**：灯带、收纳盒、挂钩、墙贴这类标品，价差 2–3 倍
- **宜家折扣区 / 样品区**：灯具和纺织品
- **本地租房群 / 公司群**：搬家人送或半卖的收纳箱、衣架
- **换季 / 大促**：床品在换季时买便宜 40%
- **花市 vs 花店**：绿植差 2–3 倍价格

## 六、省钱原则（写进方案的"省钱提示"）

1. **先改后买**：把家具挪一挪、杂物清一清，有时根本不用花钱。
2. **一物多用**：收纳凳=凳子+收纳；盐灯=灯+氛围；屏风=隔断+挡冲。
3. **只买能带走的**：大件家具在合租房是负债。
4. **一次性买齐同色系**：分批买最容易变成"杂货铺"，先定色卡再下单。
5. **别在装饰品上超支**：装饰类总预算控制在总预算的 15% 以内。
6. **留 10% 机动金**：装完一定会发现缺几件小东西（挂钩、扎带、延长线）。
