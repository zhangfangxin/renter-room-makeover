# 免破坏改造手法库

## 分级定义

| 等级 | 含义 | 默认态度 |
|---|---|---|
| **L0** | 纯摆放，零痕迹 | 随便做 |
| **L1** | 可逆粘贴，撕除后基本无痕 | 做，但先小面积测试 |
| **L2** | 免打孔支撑（摩擦/重力/夹紧），不伤墙体 | 做，注意承重上限 |
| **L3** | 微损（打孔、更换固定件） | 标 `[需房东同意]`，保留原件，附复原方法 |

向用户输出时每条建议都带上等级标签，例如 `[L1] [¥25] [★可带走]`。

## L0 · 纯摆放

| 手法 | 场景 | 要点 |
|---|---|---|
| 家具重新布局 | 床横放/竖放、书桌靠窗 | 先解决床的朝向，其余家具围着床排 |
| 床靠墙留 5cm 缝 | 防潮、避免墙面摩擦黑印 | 北方暖气片上方尤其要留 |
| 家具分区代替隔断 | 小房间划出工作/睡眠区 | 用**书架背对床**、沙发背对床形成视觉墙 |
| 地毯划定领域 | 一进门就觉得"这片是我的" | 尺寸至少盖住床前 60cm 通行面 |
| 落地灯/氛围灯 | 替代惨白顶灯 | 不占墙面，完全可带走 |
| 布艺盖丑 | 旧沙发、丑衣柜、花色床架 | 沙发巾/盖布，比换家具便宜 10 倍 |
| 床下收纳箱 | 换季衣物、被子 | 带轮款方便拉出；**床下不放杂物是风水要求也是整洁要求** |

## L1 · 可逆粘贴（先测后贴）

**测试流程（必须写进方案）**：在衣柜背后或床后墙角贴一小块 → 24–48 小时后撕下 → 无掉漆再大面积施工。

| 材料 | 承重 | 适用墙面 | 单价 | 撕除方式 |
|---|---|---|---|---|
| 3M 无痕胶条（Command） | 0.5–3kg | 乳胶漆、瓷砖、玻璃、木面 | ¥20–40/组 | 垂直下拉胶条，不留胶 |
| 免钉胶（液体钉） | 5–20kg | 多数硬质墙面 | ¥15–30/支 | 美工刀切入 + 除胶剂；**可能带漆，慎用** |
| 纳米双面胶（水洗胶） | 1–3kg | 光滑面为主 | ¥10–20 | 水洗/揉搓即可去除 |
| 魔术贴（背胶） | 0.5–2kg | 地毯墙、布面 | ¥10–20 | 直接撕 |
| 静电玻璃贴 | 0kg（无胶） | 玻璃、窗 | ¥15–40/㎡ | 一撕即下，可重复用 |
| 自粘 PVC 墙纸/墙贴 | — | 光滑腻子墙、瓷砖 | ¥8–25/㎡ | 热风枪/吹风机加热后撕；**有掉漆风险** |
| 磁性挂钩 | 2–5kg | 防盗门、冰箱、铁质 | ¥8–20 | 直接取 |
| 白板贴/留言板贴 | — | 门后、衣柜门 | ¥20–50 | 可撕 |

**禁用场景**：
- 起皮、掉粉、发霉的墙 → 任何胶都会带下一片
- 硅藻泥、艺术漆、墙布 → 无痕胶粘不住且易留痕
- 石膏板隔断 → 表面纸面层很脆弱，撕的时候容易整块起皮
- 贵重壁纸 → 一律不贴

| 吸盘置物架 | 卫生间、瓷砖墙 | 必须光滑无纹理瓷砖；定期重吸 | ¥20–60 |
| 靠墙落地全身镜 | 穿衣镜 | 靠墙斜放 + 防滑垫，**不要挂墙** | ¥60–150 |
| 折叠屏风 / 布艺屏风 | 挡门冲、挡穿堂、换衣遮挡 | 可折走，零破坏 | ¥80–200 |
| 懒人沙发 / 豆袋 | 造一个"治愈角落" | 完全可带走 | ¥100–300 |

## L3 · 微损（必须 `[需房东同意]` + 保留原件）

| 做法 | 复原方式 | 复原成本 |
|---|---|---|
| 打孔挂画 / 装窗帘轨 | 补墙膏 + 同色乳胶漆点涂 | ¥10–30 |
| 换吸顶灯 | 保留原灯，退租装回 | ¥0（工时 10 分钟） |
| 换花洒 / 龙头 | 保留原件装回 | ¥0 |
| 换开关插座面板 | 保留原件 | ¥0 |
| 装智能门锁 | 保留原锁（部分锁体可无损替换） | ¥0–50 |
| 贴 PVC 地板贴 | 吹风机加热撕除，残留胶用除胶剂 | ¥30–60 + 工时 |

**沟通话术**（可以给用户）："我想挂个画/换个灯，会保留原来的，退租时恢复原样，可以吗？"——绝大多数房东对"可复原"的改动是同意的。

## 墙面材质判断表（决定能不能贴/挂）

| 墙面 | 敲击声 | 能否用无痕胶 | 能否打孔 |
|---|---|---|---|
| 乳胶漆（实墙） | 沉闷实心 | 可以（先测） | 可以，易补 |
| 瓷砖 | 清脆 | 可以（光滑面效果好） | 可以，但需瓷砖钻头 |
| 壁纸 | 空心感 | **不建议** | 不建议 |
| 石膏板隔断 | 明显空鼓 | **不可以**（纸面易撕坏） | 需专用空心锚栓，承重 <5kg |
| 硅藻泥 | 松软 | 不可以 | 可以但难补 |
| 已起皮/发霉 | — | 一律不行 | 一律不行 |

## 退租复原工具箱（¥50 以内备齐）

- 除胶剂 / 酒精 / 风油精（除胶痕）¥10–20
- 补墙膏（牙膏状，挤进去抹平）¥15–25
- 同色乳胶漆小罐（用原墙色卡比对）¥15–30
- 吹风机 / 热风枪（撕墙纸、撕地板贴）已有
- 美工刀 + 铲刀 ¥10
- 魔术海绵（擦墙面黑印）¥5

**复原顺序**：摘装饰 → 除胶 → 补孔 → 点漆 → 拆架 → 清洁 → 家具归位（按入住时的照片，所以**入住当天要拍照留证**）。

## 绝对禁止清单

- 拆墙、砸地、改水电、改燃气
- 拆掉房东固定家具并丢弃（可以挪位、可以遮盖，不能扔）
- 在石膏板隔断上挂重（电视、大画框、吊柜）
- 堵住消防通道 / 遮住烟感报警器 / 遮挡电表水表
- 遮挡窗户导致无法逃生（封死的遮光方案不可取）
- 使用明火香薰大量熏燃（消防风险），改用电熏或无火香薰
- 大功率电器共用老旧插座（合租房线路老，注意总功率）
