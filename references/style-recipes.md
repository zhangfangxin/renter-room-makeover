# 风格配方（合租房可落地版）

## 通用铁律

1. **60-30-10 配色**：主色 60%（床品+窗帘+地毯）、辅色 30%（家具/大件布艺）、点缀色 10%（抱枕/装饰/植物）。
2. **墙面不动的前提下，房间 60% 的视觉由床品 + 窗帘 + 地毯决定** → 想换风格先换这三样。
3. **色温统一**：同一空间内所有光源色温差不超过 500K，否则再好看的软装也显廉价。
4. 合租房落地难度 = 需要打孔/换家具的程度，优先选难度 ★ 的方案。

---

## 1. 奶油风 ★（最推荐，容错率最高）

- **色彩**：主色 奶油白/燕麦 #F5EFE6 · 辅色 浅木色 #D9C3A9 · 点缀 焦糖 #B07D4A
- **材质**：绒面、针织、陶瓷、藤编、圆润造型
- **灯光**：2700K 暖黄，柔光罩，绝不用冷白
- **清单**：奶油色水洗棉四件套 ¥100–200 / 米白遮光帘 ¥80–150 / 奶白短绒地毯 ¥80–200 / 针织抱枕 ×2 ¥40 / 陶瓷花瓶+干花 ¥40 / 藤编收纳篮 ¥30
- **适配**：采光 A–C 都能用，暗间尤其友好（浅色提亮）
- **风水调性**：土金系，稳定、安神，适合卧室
- **踩坑**：全奶油容易显脏，务必加一点焦糖/深棕压住

## 2. 原木日式 ★★

- **色彩**：主色 米白 #EFE9DF · 辅色 原木 #C8A87C · 点缀 墨绿 #4A5D4E
- **材质**：木材、棉麻、纸（纸质灯罩）、竹
- **灯光**：2700–3000K，纸质/布艺灯罩
- **清单**：原木色折叠桌 ¥100–250 / 棉麻床品 ¥120–220 / 纸质落地灯 ¥80–150 / 竹帘或木百叶 ¥80–200 / 榻榻米地垫 ¥60–150 / 矮桌 ¥100
- **适配**：小房间特别合适（低矮家具显高）；采光 A–B 最佳
- **风水调性**：木土系，主生发、舒缓
- **踩坑**：木色太多会显旧，用白墙/白床品留白

## 3. 侘寂 / 新中式 ★★

- **色彩**：主色 灰褐 #A89F91 · 辅色 墨黑 #2E2C29 · 点缀 枯枝/陶土色
- **材质**：粗陶、亚麻、枯枝、宣纸、石
- **灯光**：2200–2700K，暗一点更有味道
- **清单**：粗陶花器 ¥40–100 / 亚麻床品 ¥150–280 / 枯枝或芦苇 ¥30 / 宣纸灯 ¥60–120 / 水墨挂画 ¥40–100 / 陶土色地毯 ¥100–200
- **适配**：采光好、房间方正；暗间会显阴
- **风水调性**：土系，沉静；适合需要"静下来"的人
- **踩坑**：暗房不要用，容易像仓库

## 4. 工业复古 ★★

- **色彩**：主色 水泥灰 #8A8A85 · 辅色 黑铁 #3A3A38 · 点缀 爱马仕橙 #C4622D
- **材质**：金属、铁艺、水泥、皮革、裸露灯泡
- **灯光**：2200K Edison 灯泡，可见灯丝
- **清单**：铁艺置物架 ¥80–200 / 皮质抱枕 ¥50–100 / 水泥纹墙贴 ¥20–50/㎡ / 金属网格照片墙 ¥40 / 爱迪生串灯 ¥30–60
- **适配**：男生/酷感偏好；层高 ≥2.7m 效果更好
- **风水调性**：金系，硬朗；卧室不宜过重，可用暖光中和
- **踩坑**：金属太多会冷，必须加木头或布艺平衡

## 5. 北欧极简 ★（最省钱）

- **色彩**：主色 白 #FFFFFF · 辅色 浅灰木 #CBBBA5 · 点缀 雾霾蓝 #7C96AB
- **材质**：白蜡木、羊毛、棉、几何图案
- **灯光**：3000–4000K，干净明亮
- **清单**：白色四件套 ¥100–180 / 几何图案抱枕 ¥30 / 白蜡木折叠桌 ¥150 / 简约收纳盒 ×5 ¥50 / 一盆琴叶榕（或仿真）¥60–120
- **适配**：采光好的房间；暗房会显冷清
- **风水调性**：金木系，清爽利落
- **踩坑**：极简≠空，缺少个人物品的"极简"最没有归属感 —— 一定要留一面照片墙

## 6. 多巴胺 / 孟菲斯 ★★★（只做小面积）

- **色彩**：奶白底 + 高饱和点缀（亮黄、湖蓝、玫红）
- **落地方式**：**只在抱枕、装饰画、小物件上使用**，大面积会烦躁
- **清单**：彩色抱枕 ×3 ¥60 / 撞色挂画 ¥40 / 彩色收纳盒 ¥30 / 彩色马克杯 ¥20
- **适配**：适合作为奶油风/北欧风的"点缀层"，不建议整屋
- **风水调性**：火系偏旺，卧室点缀即可，不宜主色

## 7. 暖调电竞 / 赛博 ★★（合租房男生高频）

- **色彩**：主色 深灰 #2B2B30 · 辅色 木色 · 点缀 RGB（固定在暖橙/青蓝，不要七彩乱闪）
- **灯光**：桌下灯带 + 屏幕挂灯 + 背景墙洗墙灯，**必须可调**
- **清单**：屏幕挂灯 ¥80–150 / RGB 灯带 ¥40–80 / 桌下理线槽 ¥20 / 人体工学坐垫 ¥80–150 / 隔音耳塞（合租刚需）¥20
- **适配**：需要工作+娱乐合一的小房间
- **风水调性**：注意"显示器正对床"要加帘遮挡（等同镜面）
- **踩坑**：RGB 七彩跑马灯最掉价，固定一个色温即可

## 按户型/条件选风格

| 条件 | 推荐 | 避开 |
|---|---|---|
| 房间 < 8㎡ | 奶油风、北欧极简 | 侘寂、工业（显压抑） |
| 采光差 / 无窗 | 奶油风（浅色提亮） | 侘寂、工业 |
| 层高 < 2.6m | 原木日式（低矮家具） | 工业（吊灯、深色） |
| 层高 > 3.0m | 工业、侘寂 | 全白极简（显空） |
| 房东家具很丑 | 奶油风（用布艺盖） | 任何需要换家具的风格 |
| 租期 < 6 个月 | 只做床品+灯光+窗帘的"色块方案" | 需要施工的风格 |
| 有猫 | 短绒地毯 + 无绳化（收纳灯带线） | 长毛地毯、真绿植（部分有毒） |

## 输出风格方案时的格式

```
推荐风格：奶油风（主）+ 多巴胺点缀（次）
色卡：#F5EFE6 主 60% / #D9C3A9 辅 30% / #B07D4A 点缀 10%
色温：全屋 2700K，工作区单独 4000K 台灯
三件定调单品：奶油色四件套 / 米白遮光帘 / 奶白短绒地毯
避雷：不要买深色大件家具，8㎡ 房间会显挤
```
