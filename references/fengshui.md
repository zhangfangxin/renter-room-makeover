# 租房风水调整手册（可逆版）

## 使用原则（写进方案前先读这四条）

1. **只用"加法"不用"减法"**：所有化解靠移动、遮挡、软化、增加来完成，绝不靠拆改。
2. **每条都要给心理学解释**：风水说法 + 环境心理学/视觉层面的解释，两者并列。用户是打工人，讲道理比讲忌讳有用。
3. **禁止绝对化断言**：不说"必定破财""不化就出事"。用"容易让人不安""长期睡不好"这类可验证的表述。
4. **和现实冲突时以居住者感受为准**：户型改不了就折中，说明折中理由，不要为了风水牺牲基本功能。

## 表达模板

> **现象**：床正对房门。
> **传统说法**：门冲床，气口直冲睡眠之人。
> **为什么真的会不舒服**：人睡着时背后/正面有开口，潜意识会有警觉，睡眠变浅；走廊的灯光和室友走动声也会直接打在脸上。
> **化解（可逆）**：① 床侧移 30–50cm 让门不直对床头 `[L0]`；② 移不动就加一道门帘或 1.2m 高的布艺屏风 `[L2 ¥60–150]`；③ 床头加厚床头板/软包 `[L0–L1]`。

---

## 一、床位（优先级最高）

| 要求 | 心理学解释 | 不能改时的折中 |
|---|---|---|
| 床头靠**实墙**，不悬空 | 背后无可见的"空隙"能降低警觉，睡得更深 | 加厚床头板 + 床头靠垫 |
| 床头**不靠窗** | 窗户有光、有风、有噪音，且心理上"背后是空的" | 加遮光帘 + 厚床头板；实在不行床头加一排矮书墙 |
| 床**不正对门** | 门是气口也是动线，直冲影响睡眠、缺乏私密 | 侧移 / 门帘 / 屏风 |
| 床**不在梁下** | 梁在头顶形成视觉压迫，"横梁压顶" | 床挪出梁下；挪不了就在梁下挂布幔弱化，或放葫芦 |
| 床头**不靠卫生间墙** | 水管噪音 + 潮气 + 心理暗示 | 床换个方向；不行就加床头软包与隔音条 |
| 镜**不正对床** | 半夜醒来看到反光受惊 | 镜子转向 / 加镜帘 / 移到衣柜门内侧 |
| 床**不紧贴空调下方** | 直吹头疼，且头顶有机器运转声 | 装空调挡风板 `[L2 ¥30]` |
| 床下**不堆杂物** | 传统说"压气"，实际是积灰、生霉、视觉乱 | 换带盖收纳箱，只放换季物 |

## 二、门与动线

- **穿堂煞**（门对窗/门对阳台）：气流直穿，冬天冷、夏天空调流失，心理上也"留不住"。化解：沙发/书架横在中间、或加门帘 `[L2 ¥30–80]`。
- **入户门正对卫生间门**：加门帘 + 卫生间门常关 + 卫生间放绿植。
- **入户门正对厨房灶**：合租房少见，用帘或高绿植遮挡。
- **门口不堆鞋杂物**：气口阻塞，实际就是一进门看着乱、心情差。用鞋架/门后挂袋解决 `[L0–L2 ¥30–80]`。
- **门要能顺畅开到底**：开合受阻意味着动线堵，也影响日常情绪。

## 三、工作位（打工人最该重视的一块）

- **背后有靠**：背靠实墙或书架，不背对门、不背对空旷。解释：背后有人来人往会分散注意力。
- **面门而不被门冲**：能看到谁进来（掌控感），但不要正对门被直冲。
- **面前开阔**：不要脸贴墙，桌面到墙留 30cm 以上，或贴一张远景图/风景画。
- **左高右低（青龙白虎）**：左手边放稍高的物件（台灯、书架、文件架），右手边保持低平。解释：多数人右手操作，右侧留空更顺手。
- **桌面整洁**：杂物堆积在风水里是"滞气"，实际是注意力被切割。
- **不坐在梁下、不背对窗**（背对窗有逆光和背后空虚感）。

## 四、光与色

- **明厅暗房**：公共区明亮，卧室用暖光偏暗（2700–3000K），利于入睡。
- **忌头顶一盏冷白吸顶灯直射**：光通量够但氛围冰冷，是合租房"不像家"的头号元凶。改成分层照明：主灯（关掉或换暖色）+ 落地灯 + 灯带 + 台灯。
- **至少 3 个光源**，且能单独开关。
- **镜子不要对着窗**（反光刺眼）也不要对着门。
- 暗间/无窗房：用暖白光 + 浅色墙面软装提亮，加一面镜子增加光反射与空间感。

## 五、五行与方位配色（用于选色，不是堆砌）

| 方位 | 五行 | 宜用色 | 合租房怎么落地 |
|---|---|---|---|
| 东 / 东南 | 木 | 绿、青 | 植物、绿植窗帘、草绿抱枕 |
| 南 | 火 | 红、橙、紫（**少量**） | 一个橙红抱枕、一幅暖色画 |
| 西 / 西北 | 金 | 白、金、银、米 | 金属灯具、白床品、银色收纳盒 |
| 北 | 水 | 蓝、黑、灰（**少量**） | 深灰地毯、蓝灰床品 |
| 中 / 东北 / 西南 | 土 | 米黄、棕、卡其 | 原木色家具、奶油色床品、藤编 |

**实践原则**：一个房间选 **1 个主色（60%）+ 1 个辅色（30%）+ 1 个点缀色（10%）**，主色优先选与你卧室方位相生的颜色。红色只做点缀，大面积红会让人烦躁。

## 六、财位（最实用的一个民俗锚点）

- **简易定位**：入户门的对角线角落（门在左→右对角；门在右→左对角）。
- **要求**：明亮、整洁、不放垃圾桶、不放杂物、不放重物压（如大柜子）。
- **布置**：常绿阔叶植物（金钱树、发财树）+ 一盏小灯 + 你珍视的小物件。
- **意义**：本质是"给房间设一个你每天会打理的角落"，仪式感带来安定感。

## 七、植物（提升归属感性价比最高的活物）

- **推荐**：绿萝、龟背竹、虎皮兰、琴叶榕、金钱树、富贵竹、吊兰（好养、耐阴、净化空气）。
- **位置**：财位（阔叶）、窗边（喜光）、书桌旁（缓解视觉疲劳）。
- **忌**：卧室放太多（夜间呼吸作用，且潮气）；带刺植物（仙人掌）不放床头，放阳台挡煞；**枯叶必须及时剪掉**——枯萎植物是最强的负面心理暗示。
- 预算：¥20–80 一盆，闲鱼/花市更便宜。

## 八、水与卫生间

- 卫生间门**常关**，马桶盖盖上。
- 卫生间保持干燥通风，放一盆耐阴植物（如虎皮兰、绿萝）。
- **卧室不放鱼缸、不放流水摆件**：潮气、噪音、水泵声影响睡眠。想"招财"放财位即可。
- 漏水的水龙头要修——传统说"漏财"，实际是浪费水 + 滴水声烦人。

## 九、化煞小物（全部可逆、全部便宜）

| 物品 | 用途 | 价位 | 说明 |
|---|---|---|---|
| 门帘 / 布帘 | 挡门冲、挡穿堂 | ¥30–80 | 首推，最实用 |
| 屏风（折叠） | 挡冲、换衣遮挡 | ¥80–200 | 可带走 |
| 布幔 / 纱幔 | 化横梁压顶 | ¥30–60 | 梁下挂一层，视觉弱化 |
| 葫芦（铜/木） | 传统化横梁、病气 | ¥20–60 | 挂床头或梁下，心理锚点 |
| 五帝钱 | 挂门后/门槛 | ¥20–50 | 用无痕挂钩，可摘 |
| 水晶 / 盐灯 | 氛围 + 心理锚点 | ¥40–120 | 盐灯同时是暖光源，一举两得 |
| 圆叶植物 | 化尖角煞 | ¥30–80 | 放在尖角家具与床之间 |
| 中国结 / 小挂饰 | 门后、窗边 | ¥10–30 | 个人痕迹，归属感用 |

## 十、尖角煞与形煞

- 柜角、桌角、墙柱尖角正对床 → 用绿植、布艺、圆角防撞条软化 `[L0 ¥10–30]`。
- 对面楼的墙角、天线、电塔正对窗 → 用窗帘 + 窗台绿植遮挡，不必过度在意。
- 房间形状不规则、有缺角 → 缺角处放一盏灯或一盆植物"补角"。

## 十一、必须提醒的理性边界

在方案里明确写一句：
> 以上风水内容属于传统居住习俗与环境心理学的结合参考，不涉及任何运势承诺。真正影响居住体验的是采光、通风、噪音、动线和整洁度——这些优先解决，风水调整作为补充。
