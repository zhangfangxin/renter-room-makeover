# 照片解读指南：从几张图读出房间格局

## 一、拍摄清单（原样发给用户）

```
1. 站在门口往里拍一张（要能同时看到门和主要家具）
2. 站在房间四个角各拍一张对角全景：开灯 + 拉开窗帘 + 横屏 + 手机 0.5x 广角
3. 窗户一张（含窗框、窗台），再拍一张"从窗户往外看"
4. 天花板一张（看梁、吸顶灯位置、层高）
5. 地面一张（材质、颜色、破损、踢脚线）
6. 每个房东固定家具各一张（衣柜、书桌、床架）
7. 卫生间、厨房各一张（合租房共用区）
8. 所有插座、网线口、空调孔的位置
9. 瑕疵特写：霉斑、渗水、裂缝、掉皮
10. 白天自然光状态补一张（判断朝向与采光）
```

提醒用户：拍的时候把地面和天花板的交界拍进去，方便判断层高和房间形状。

## 二、没有尺寸怎么办：用参照物当比例尺

| 参照物 | 标准尺寸 |
|---|---|
| 入户门 / 房间门 | 宽 0.80–0.90m（取 0.85m），高 2.0–2.1m |
| 开关 / 插座面板 | 86 × 86 mm（这是最可靠的微型标尺） |
| 地砖 | 600×600 或 800×800 mm |
| 木地板板宽 | 常见 120 / 150 / 190 mm |
| 踢脚线高度 | 80–100 mm |
| 床 | 单人 0.9 / 1.2m，双人 1.5 / 1.8m，长 2.0m |
| 床头柜 | 宽 40–50cm，高 50–55cm |
| 标准木椅座高 | 45cm |
| A4 纸 | 210 × 297 mm |
| 矿泉水瓶 | 高约 23cm |
| 鞋盒 | 约 33 × 22 cm |

**估算方法**：数出长边有几块地砖、短边有几块 → 相乘得面积；或用门宽 0.85m 在图上量出比例。
报告中一律标注"估算值 ±10%"，不要给精确到小数点的假数字。

## 三、逐项读数清单

### 层高
常见 2.6 / 2.8 / 3.0m。低于 2.6m 忌用大吊灯和顶天立地深色柜（压抑）；高于 3.0m 可用纵向软装拉高视觉。

### 朝向与采光
- 先找窗户在哪面墙，再用用户说的"几点有太阳"交叉验证。
- 中国大部分地区：南向最佳（全天有光不暴晒）；东向上午光、下午暗；西向下午**西晒**（夏热，必须遮光帘）；北向全天柔和无直射（需人工补光）。
- 采光分级：
  - **A** 南/东南，窗地比大，白天基本不用开灯
  - **B** 东/西南，中窗，上午或下午有直射
  - **C** 小窗 / 北向 / 天井 / 被对面楼遮挡
  - **D** 无窗（隔断间、客厅隔出来的房间）→ 重点补光 + 处理通风与压抑感
- 从照片判断：地面有无明显光斑、墙面是否有明暗渐变、拍照时是否必须开灯。

### 通风
看有无对开窗/对开门（形成穿堂风）、有无卫生间窗、厨房有无排烟。无窗隔断间必须建议空气净化或定时开门通风。

### 门与窗的位置关系
记录：门是否能直对窗（穿堂）、门是否正对床、门是否正对卫生间门、入户门是否正对阳台。这四条直接决定风水清单。

### 梁、柱、管道
- 梁：天花板上的凸起。梁下忌放床、书桌（压迫感）。
- 竖管/排水管：通常在卫生间墙或阳台，可用麻绳/绿植缠绕弱化。
- 柱角：视觉尖角，需软化。

### 固定家具
凡是房东留下的、搬不走的（衣柜、床架、旧书桌、空调）都要单列。它们通常又丑又占地方，方案要围绕它们做"遮丑 + 借力"（盖布、贴纸、靠布帘挡、当隔断用）。

### 插座与网口
数清楚数量和位置，这决定了工作区能放哪、能不能加落地灯和灯带。**插座不足是合租房最常见的隐形痛点**，方案里要预留排插/理线方案。

### 缺陷
霉斑（通风差/渗水）、墙面掉皮、地砖空鼓、窗框漏风、隔音差（石膏板隔断）、空调对着床头吹。

## 四、房间形状识别

| 形状 | 特征 | 布局要点 |
|---|---|---|
| 矩形 | 最常见 | 家具沿长边布置，短边留动线 |
| L 形 / 手枪形 | 有凹角 | 凹角做衣柜或工作区，凸出部分做睡眠区 |
| 狭长形 | 长宽比 > 2:1 | 用矮柜/帘子做软分区，避免一览到底 |
| 斜顶 / 阁楼 | 一面墙倾斜 | 低处做收纳，高处做床头 |
| 石膏板隔断间 | 墙敲起来空、隔音差 | **绝对不能挂重物**，所有挂墙方案作废，改落地款 |


## 六、待确认清单（照片读不出时必须问）

1. 房间大概几平米？（或"铺的是 60cm 还是 80cm 地砖"）
2. 窗朝哪边？大概几点太阳能照进来？
3. 墙是乳胶漆还是贴了壁纸？（决定能不能用无痕胶）
4. 那面墙是实墙还是隔断板？敲起来空不空？
5. 还剩多久租期？房东允许打孔吗？

## 七、常见误判（别踩）

- **广角畸变**：0.5x 会让房间显大 20–30%，不要按照片直接估面积。
- **开灯拍的照片**会低估暗区，白天补拍那张很关键。
- **深色地面 + 深色家具**会让空间显小 15%，浅色软装能救回来。
- **照片里没出现的东西不等于不存在**（比如床底下的杂物、墙后的管道），涉及承重和安全时保守处理。
- 不要凭"看起来像"就断定材质，拿不准就写"疑似"，并给出测试方法（如墙贴测试：先在角落贴一小块，24 小时后撕下看是否掉漆）。
