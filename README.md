# renter-room-makeover 🏠

[English](README_EN.md) | 中文

<img src="assets/icon.svg" width="96" align="right" alt="icon">

一个给**城市合租打工人**用的房间改造设计 Skill。

你拍几张房间照片发过去，它帮你读出格局、诊断问题、给出改造方案——
优先低预算、优先不打孔、东西退租能带走，顺带把风水讲究用能复原的方式落地。
还能直接**渲染出改造后的逼真效果图**，让你一眼看到「改完长什么样」。

> 第一目标不是「好看」，是**归属感**。让一个随时可能搬走的临时住所，变成「我的地方」。

## 四条底线

任何一条不满足的方案都会被降权或替换掉。

| 底线 | 具体怎么执行 |
| --- | --- |
| **少花钱** | 默认总预算 ¥200–800，单品优先 <¥150。有「花钱效率排序」，超预算时按序从后往前砍 |
| **少破坏** | 手法分 L0 纯摆放 / L1 可逆粘贴 / L2 免打孔 / L3 微损。L3 必须标 `[需房东同意]` 并附复原方法；禁止任何拆墙、砸地、改水电的建议 |
| **可带走** | 优先退租能打包带走的物品，清单里用 ★ 标出 |
| **讲风水，但理性讲** | 一律用「移动、遮挡、软化、增加」化解，绝不靠结构改动。每条建议都附一句环境心理学解释，禁止绝对化断言 |

## 怎么用

安装后直接说人话就行，不用记命令：

- 「我合租的主卧，发你照片，帮我改一下，预算 500，不想打孔」
- 「帮我看看这张图里床放得对不对」
- 「出租屋怎么弄出氛围感」
- 「帮我出一张改造后的效果图，我想一眼看到长什么样」
- 「下个月退租了，这些改造怎么复原」

**照片怎么拍**（技能会发给你，也可以先看这里）：

```
1. 站在门口往里拍一张（看到门 + 主要家具）
2. 站在四个角各拍一张对角全景（开灯、拉窗帘、横屏、0.5x 广角）
3. 窗户一张（含窗框、窗外），白天自然光下再补一张
4. 天花板一张（看梁、灯位）  5. 地面一张（看材质、破损）
6. 房东的固定家具各一张      7. 卫生间、厨房各一张
8. 插座、网口、空调孔位置    9. 瑕疵特写：霉斑、渗水、裂缝
```

## 会输出什么

1. **房间档案** — 面积（用门宽 0.85m / 地砖 60cm 当比例尺估算）、层高、朝向采光等级 A–D、梁柱、固定家具、插座、缺陷
2. **问题诊断** — 每条说清「现状 → 为什么难受 → 约束内怎么解」
3. **格局与布局** — SVG 平面示意图，现状 vs 改造后；1 主方案 + 1 备选
4. **分区设计** — 睡眠区 / 工作区 / 治愈角落 / 收纳区
5. **风水调整清单** — 按 P0/P1/P2 排优先级，每条带化解手法、可逆性、心理学解释
6. **采购清单** — 分 A/B/C 档，含单价区间、破坏等级、★可带走、渠道建议
7. **执行计划** — Day 1（0 元能做的）/ Week 1 / Month 1 / 退租复原
8. **逼真效果图** — 有照片就图生图（保持格局、只改软装灯光），没照片就文生图（风格示意）；可出「改造前 → 改造后」同机位对比。内置工具直接出图，也支持按你指定的平台（Midjourney / SD / 即梦 / 通义万相 / 可灵等）输出可直接粘贴的提示词

需要「能看图、能存下来」的版本时，会用 `assets/plan-template.html` 生成可视化方案页，效果图一并嵌进去。

## 几条设计上的取舍

写这个技能时做的判断，不一定主流，说明理由：

- **灯光优先于一切。** 换掉那盏惨白顶灯的体验提升，通常大于任何其他单笔支出。卧室 2700–3000K，工作区 4000K，同空间色温差不超过 500K。
- **先大面积后细节。** 不动墙的前提下，房间 60% 的视觉由「床品 + 窗帘 + 地毯」决定。预算优先砸这三样，装饰画摆件排在最后。
- **收纳先做「藏」而不是「买柜子」。** 床下箱、门后挂袋、顶天立地架，都比新买柜子便宜且不占地。
- **归属感的第一抓手是「可控」，不是「好看」。** 能拉上的帘子、能调暗的灯、一块属于你的地毯、一个 0.6㎡ 的角落——这些比装饰画重要得多。
- **读不到的信息不许编。** 朝向、面积、梁位判断不了就列「待确认清单」去问，不臆测。

## 预算汇总脚本

采购项多的时候用它算，避免人工加总出错：

```bash
python scripts/budget_sheet.py assets/sample-plan.json
python scripts/budget_sheet.py my-plan.json --out 采购清单.md
python scripts/budget_sheet.py my-plan.json --tier A B    # 只统计指定档位
```

输入格式见 `assets/sample-plan.json`。支持单价区间（`price_low` / `price_high`），会自动汇总成区间总价并判定是否超预算。

## 说明

- 所有价格均为参考区间，随城市与平台浮动，实际以购买时为准。
- 风水内容属于传统居住习俗与环境心理学的结合参考，不涉及任何运势承诺。真正影响居住体验的是采光、通风、噪音、动线与整洁度——这些优先解决。
- 涉及打孔、更换固定件的建议均会标注 `[需房东同意]`，动手前请与房东沟通并保留原件。
